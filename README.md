# Mapping immune-cell contexts and prioritizing candidate genes for venous thromboembolism susceptibility

Analysis code for OneK1K immune-cell cis-eQTL mapping, FinnGen VTE discovery,
independent VTE meta-GWAS replication, and HCA COVID-19 cellular contextualization.

The repository contains code and configuration templates. Analysis inputs and
outputs reside in a separate workspace designated by `PROJECT_DIR`. Obtain the
required datasets from their original providers under their applicable terms.

## Setup

Use Python 3.12, R, Bash, and the external tools listed in
[environment documentation](docs/ENVIRONMENT.md).

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
Rscript tools/install_r_packages.R
python tools/init_workspace.py /path/to/analysis_workspace
export PROJECT_DIR=/path/to/analysis_workspace
```

Edit `config/project_paths.tsv` inside that workspace and place the additional
resources at the locations described in [data inputs](docs/DATA_INPUTS.md).
The initialization command creates templates only and does not download data.

## Run

The workflow has explicit stages because LD and BESD preparation occurs between
eQTL mapping and eGene summarization. List stages and inspect a command before
running it:

```bash
python run.py list
python run.py run eqtl-inputs --project "$PROJECT_DIR" --dry-run
python run.py run eqtl-inputs --project "$PROJECT_DIR"
```

Follow [the execution order](docs/WORKFLOW.md). A selected stage runs its commands
sequentially and stops on the first failure. Individual scripts can also be run
with `PROJECT_DIR` exported. Pipeline READMEs describe inputs, settings, and
outputs in more detail. Analysis commands can take substantial time and require
the complete input datasets.

## Verification

```bash
python tools/validate_release.py
python -m unittest discover -s tests -v
```

These checks validate source syntax, repository structure, relocation, and
selected numerical operations. They do not substitute for rerunning the full
analysis on the original data. [Validation notes](docs/VALIDATION.md) record the
checks performed for this release.

Two archived bootstrap lower bounds are not exactly reproduced by the retained
summary script; see the validation notes before regenerating Figure 6 or Table
S12. The corresponding effect estimates and FDR values match.

## Figures and tables

Plotting scripts generate statistical panels and source tables. Figure 1 is an
author-prepared study schematic. Final manuscript composites may include
author-arranged artwork; panel exports and final submitted layouts should be
distinguished when reproducing figures. Numerical results are generated by the
analysis and table scripts, not by composite assembly.

## Citation and data access

to the analyses used. Software versions and resource requirements are documented
in `docs/`. This repository does not grant access to controlled datasets.

## Current manuscript update (2026-10-09)

Standard LDSC replaces the archived custom regression in `meta-qc`. The primary
fit uses standard munging and the default two-step estimator; chi-square < 80
is a QQ display restriction only. See the Result 3 README for the isolated LDSC
environment. `meta-tables` can export S6-S8 from completed analysis outputs.

`covid-tables` produces S10-S12. `covid-sensitivity` calculates continuous donor
expression associations before/after categorical collection-day COVID severity
adjustment, exports current S13, and generates Figures S3-S5. Derived sensitivity
files go to `manuscript_results/current_sensitivity/` in the workspace.
Original data and previous manuscript output directories need not be modified;
use a separate workspace with read-only input links to validate exports.

A code structure listing is in `docs/CODE_STRUCTURE.txt`.
`tools/package_supplementary_tables.py` packages explicitly selected S1-S13 XLSX
files and checks current S8/S12/S13 identities before creating a new archive.
Run it with `--help` for the selection syntax.
