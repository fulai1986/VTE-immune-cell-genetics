# Execution order

Run stages with `python run.py run STAGE --project /path/to/workspace` from the
repository root. Use `--dry-run` to print commands. The data workspace and source
repository can be relocated independently.

| Order | Stage | Purpose |
| --- | --- | --- |
| 1 | `eqtl-inputs` | Validate inputs, construct 14-cell labels, pseudobulk, covariates and genotype sample map |
| 2 | `eqtl-mapping` | Fit cis-eQTL models for 14 cell types across chromosomes 1-22 |
| 3 | `ld-reference` | Build OneK1K PLINK reference with allele-specific variant IDs |
| 4 | `smr-besd` | Export eQTL qfiles and SMR BESD files |
| 5 | `egenes` | LD effective-test correction and cell-wise eGene calls |
| 6 | `eqtl-qc` | Published OneK1K concordance and Tables S1-S3 |
| 7 | `finngen-preparation` | GRCh38-to-GRCh37 conversion and LD-reference harmonization |
| 8 | `finngen-discovery` | SMR for all 14 cell types, colocalization and tier assignment |
| 9 | `discovery-tables` | Table 1 and Tables S4-S5 |
| 10 | `meta-gwas` | Cohort standardization, UKB conversion, METAL and LD harmonization |
| 11 | `meta-qc` | LD-score calibration and Tables S6-S8 |
| 12 | `replication` | SMR/HEIDI/colocalization replication, Figure 5 and Table S9 |
| 13 | `hca-mapping` | Healthy reference correspondence, Seurat sensitivity and fixed annotation export |
| 14 | `covid-analysis` | Donor expression, detectability, Hallmark scores, LIANA and group contrasts |
| 15 | `covid-tables` | Tables S10-S12 (S12 contains grouped Figure 6 results) |
| 16 | `covid-sensitivity` | Continuous severity analysis, Table S13 and Figures S3-S5 |
| 17 | `figures-2-4` | Statistical figures for Results 1-3 |
| 18 | `figure-6-panels` | Figure 6 panels and supplementary mapping figures |

Stages 7-9 and 10-11 both depend on the OneK1K reference. Replication requires
both discovery and the independent meta-GWAS. HCA detectability uses the
replication source table generated by the `replication` stage.

The publication analysis settings are retained in the scripts. In particular,
the independent meta-GWAS primary variant set requires at least three cohorts;
the gene-level effective-test correction and eQTL testing implementation are
preserved. LIANA is evaluated per eligible donor. Grouped analyses use the lower
and upper expression tertiles, with outcome-specific donor availability.

Pipeline READMEs provide commands that can be run directly from each pipeline
directory, with `PROJECT_DIR` exported. The root runner is the authoritative
cross-pipeline execution order. Existing-output skip behavior in the original
analysis scripts is retained; use a fresh workspace for a complete rerun.

Output stems containing `figure5` in Result 5 source tables are established
input/output identifiers used by the analysis; manuscript numbering is Figure 6.
The input location `gwas/replication/finngen_r13` is a retained directory name;
FinnGen is the discovery GWAS, as specified in the dataset manifest.

`meta-tables` repeats only the S6-S8 export steps after a completed `meta-qc` run.
Set `STANDARD_LDSC_RUN_DIR` to reuse an existing standard LDSC directory.
`covid-sensitivity` requires `covid-analysis`, including the exported D0 sample
metadata and donor-level Hallmark and LIANA summaries. No prior S13 or archived
severity result is required. It uses only collection-day severity as a covariate.
Historical scripts are kept outside the publication repository and are not included in the GitHub code package.
