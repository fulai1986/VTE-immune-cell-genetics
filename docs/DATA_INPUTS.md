# Data inputs

`PROJECT_DIR` points to the analysis workspace. Paths listed below are relative
to that workspace unless configured in `config/project_paths.tsv`.

## OneK1K

The path template defines the GEO raw count archive (GSE196735), CELLxGENE H5AD,
published supplementary annotation tables, genotype sample map, genotype PCs,
GENCODE v19 gene annotation, and imputation archive directory. Use absolute paths
in this local configuration. Genotype access is governed by the original data
provider. Imputation archives are named `chr_1.zip` through `chr_22.zip` and contain
`chrN.dose.vcf.gz` and `chrN.info.gz`.

Supply encrypted archive passwords through `IMPUTE_PASS_A` and `IMPUTE_PASS_B`.
The supplied archive grouping uses A for chromosomes 1, 10, 11 and 12 and B for
the remaining autosomes. Set both variables to the same value if all archives
share a password. Credentials belong in the local environment.

The mapping stage reads extracted raw count files from `scratch/GSE196735_RAW/`.
The pseudobulk step extracts these from the count archive. Published concordance
tables belong in `reference/onek1k_official/esnp/`, named
`cd4nc_esnp_table.tsv.gz`, `cd4et_esnp_table.tsv.gz`, and the corresponding
published identifiers for the remaining cell types.

## GWAS and LD-score resources

Edit `gwas/config/gwas_dataset_manifest.tsv`, initialized from the example.
The four independent replication datasets are the deCODE Danish, Icelandic and
Intermountain components and OpenGWAS `ukb-d-I9_VTE`. FinnGen R13 `I9_VTE` is the
discovery dataset. The template specifies the expected file names and cohort
sample sizes.

Place the UCSC conversion chain at
`gwas/external/ucsc/hg38ToHg19.over.chain.gz`. The European HapMap3 LD-score
resource belongs in `tools/ldsc_reference/eur_w_ld_chr/`. The OneK1K PLINK LD
reference and eQTL BESD files are generated by the included preparation scripts.

## HCA and Hallmark resources

Place the processed COVID-19 Cell Atlas `COVID-19 PBMC Ncl-Cambridge-UCL` file at
`covid_validation/stephenson_hca/covid_portal.h5ad`. The supplied readers use the
original H5AD layout, including `obs` category encodings, cell identifiers,
`sample_id`, `Status`, `Collection_Day`, and `full_clustering`; expression is read
from the processed matrix. Preserve its observation order.

Place the MSigDB human Hallmark gene-set file at
`resources/msigdb/h.all.v2025.1.Hs.symbols.gmt`, obtained under the MSigDB terms.
LIANA uses its consensus ligand-receptor resource. Healthy HCA cells determine
the mapping; the fixed mapping is then applied to COVID cells. Platelets retain
their original HCA compartment identity.

## Generated files

The scripts create `metadata/`, `results/`, `gwas/`, `covid_validation/`, and
`manuscript_results/` products inside the workspace. Donor-level inputs, genotype
files and raw matrices are not distributed in this code repository. Supplementary
manuscript tables and figures are distributed with the manuscript separately.

## Continuous severity sensitivity inputs

The `covid-analysis` stage exports `covid_d0_same_cell_program_sample_metadata.tsv`,
including `Status_on_day_collection_summary`. Together with the donor expression,
CD8 ET/platelet scores and LIANA axis/edge summaries in the same result directory,
this supplies `covid-sensitivity`. The five labels are Asymptomatic, Mild, Moderate,
Severe and Critical. No archived sensitivity table is needed as input.
